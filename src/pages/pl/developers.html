Dla deweloperów

Dostawa robotem w jednym zapytaniu.

REST API do tworzenia i śledzenia dostaw oraz webhooki przy każdej zmianie statusu. Wypróbuj wszystko poniżej — w przeglądarce, bez konta.

Podgląd Publiczne API jest w przygotowaniu. Przykłady pokazują planowany kształt i mogą się jeszcze zmienić. Klienci pilotażowi dostają dostęp do wersji beta.

Poproś o dostęp do bety Wypróbuj plac zabaw

Przewodnik startowy

Trzy kroki do pierwszej dostawy.

  1. 1

    Klucz API

    Wygenerujesz go w panelu, w zakładce Integracje. Klucze testowe zaczynają się od dng_test_, produkcyjne od dng_live_.

    Authorization: Bearer dng_test_…
  2. 2

    Pierwsza dostawa

    Wyślij adres odbioru i doręczenia. W odpowiedzi dostaniesz identyfikator i szacowany czas dotarcia.

    POST /v1/deliveries
  3. 3

    Webhook

    Podaj adres URL, a przy każdej zmianie statusu wyślemy podpisane zdarzenie — od przyjęcia do doręczenia.

    delivery.delivered

Plac zabaw

Wyślij zapytanie. Zobacz odpowiedź.

Wszystko dzieje się w Twojej przeglądarce na danych symulowanych — nic nie jest wysyłane na serwer.

POST /v1/deliveries
Kliknij „Wyślij zapytanie”, aby zobaczyć odpowiedź.

Weryfikacja podpisu

            
Każde zdarzenie ma nagłówek DNG-Signature z czasem i podpisem HMAC-SHA256 treści. Sprawdź go, zanim przetworzysz zdarzenie, i odrzucaj zdarzenia starsze niż 5 minut.

            

          

        

      

    


    

      

        

          
Skrót dokumentacji

          
Endpointy, statusy, błędy.

        

        

          

            
Endpointy

            

              
POST /v1/deliveriesUtwórz dostawę

              
GET /v1/deliveries/{id}Status dostawy

              
POST /v1/deliveries/{id}/cancelAnuluj dostawę

              
GET /v1/robotsRoboty i ich stan

            

          

          

            
Statusy i zdarzenia

            

              
queueddelivery.created — przyjęta

              
assigneddelivery.assigned — robot przydzielony

              
en_routedelivery.en_route — w drodze

              
delivereddelivery.delivered — odebrana PIN-em

              
cancelleddelivery.cancelled — anulowana

            

          

          

            
Kody błędów

            

              
400Niepoprawny JSON

              
401Brak lub zły klucz API

              
404Nie ma takiej dostawy

              
409Dostawy nie można już anulować

              
422Brakujące lub błędne pola
