Quick start

Three steps to your first delivery.

  1. 1

    API key

    Generate it in the dashboard under Integrations. Test keys start with dng_test_, live keys with dng_live_.

    Authorization: Bearer dng_test_…
  2. 2

    First delivery

    Send the pick-up and drop-off address. The response contains the delivery ID and the estimated arrival time.

    POST /v1/deliveries
  3. 3

    Webhook

    Give us a URL and we’ll send a signed event on every status change — from accepted to delivered.

    delivery.delivered

Verifying the signature

            
Every event carries a DNG-Signature header with a timestamp and an HMAC-SHA256 signature of the body. Check it before processing the event, and reject events older than 5 minutes.

            

          

        

      

    


    

      

        

          
Reference at a glance

          
Endpoints, statuses, errors.

        

        

          

            
Endpoints

            

              
POST /v1/deliveriesCreate a delivery

              
GET /v1/deliveries/{id}Delivery status

              
POST /v1/deliveries/{id}/cancelCancel a delivery

              
GET /v1/robotsRobots and their state

            

          

          

            
Statuses and events

            

              
queueddelivery.created — accepted

              
assigneddelivery.assigned — robot assigned

              
en_routedelivery.en_route — on its way

              
delivereddelivery.delivered — collected with PIN

              
cancelleddelivery.cancelled — cancelled

            

          

          

            
Error codes

            

              
400Invalid JSON

              
401Missing or wrong API key

              
404No such delivery

              
409Delivery can no longer be cancelled

              
422Missing or invalid fields
